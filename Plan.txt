I need to build a comprehensive, scalable resource-sharing web application dedicated to Diploma students. The platform will serve as a centralized hub where administrators can upload links to study materials (PDFs, notes, books) and students can easily filter, find, and read these resources.
Design System & UI/UX Guidelines:
    Theme: Clean, modern, minimalist white background (#FFFFFF or #FAFAFA).
    Styling: Use a modern UI framework (like Tailwind CSS). Focus on high contrast for text, subtle drop shadows for cards, and rounded corners to make it feel premium.
    Typography: Modern sans-serif fonts (e.g., Inter or Roboto).
    Responsiveness: Must be 100% mobile-friendly, as most students will access this via smartphones.
    Navigation: A fixed top navigation bar with breadcrumbs (e.g., Computer Science > 4th Semester > Database Management Systems > Notes) so users never get lost.
Also Make Another Layout Style for Mobile Users, Like When Someone Open the site in mobile It shouldn't break its UI It should be resize according to mobile screen.

1. Authentication & Role Management:
Implement a secure dual-role system.
    Student (User) Flow:
        Must sign in using Google OAuth (Single Sign-On).
        On the very first login, redirect to a mandatory registration page to collect: Full Name, Title (Student/Alumni), Institute Name, and Registration/Roll Number.
        Students have "Read-Only" access to resources but can interact with them (bookmark, rate).
    Admin Flow:
        Secure backend login route (/admin/auth) using a specific Email and encrypted Password.
        Admins have full CRUD (Create, Read, Update, Delete) permissions across the entire database.

2. Core Architecture & Navigation:
The user journey must follow a logical, tiered drill-down menu structure:
    Branch/Department: (e.g., Computer Science and Technology, Civil, Mechanical).
    Semester: Choose from 1st to 6th Semester.
    Subjects: Display the relevant subjects for that semester (e.g., Java Programming, DBMS).
    Resource Filter Tabs: Once a subject is selected, provide tabbed filtering for the material type:
        Notes
        Books
        Model Question Papers
        Lab Manuals

3. Basic Features:
    Admin Dashboard: A private panel to upload external links (Google Drive, Dropbox, etc.), assign them to the correct Branch/Semester/Subject/Category, and edit/delete them.
    User Management System: Admins can view a table of all registered students, edit their profiles, or ban/suspend accounts if necessary.
    Dynamic Routing: URLs should be clean and shareable (e.g., /cs/semester-4/java/notes).

4. Advanced Features:
    Global Instant Search: A search bar (Cmd/Ctrl + K shortcut) that allows users to instantly search for a specific book title, subject, or question paper year across the whole site.
    Inline PDF Previewer: Instead of blindly clicking a link, integrate a viewer (like PDF.js or an iframe) so students can preview the document directly on the website before downloading.
    Resource Request System: A form where students can request missing notes or past papers. Admins see these requests in their dashboard.
    Bookmark System: A "Save for Later" button on resources, allowing students to build a personalized dashboard of their most used materials.
    Quality Ratings: A simple Upvote/Downvote or 5-star rating system on links so students know which notes are the best.
    Link Health Checker: A background utility or manual Admin button to verify if the provided external links are still active (not returning 404 errors).
Database Schema Requirements:
Please structure the backend with at least the following models:
    User (Role, Google ID, Name, Institute, Reg Number)
    Admin (Email, Hashed Password)
    Department (Name)
    Course/Subject (Name, Semester Number, Department ID)
    Resource (Title, URL, Category, Subject ID, Uploader ID, Ratings, IsActive)
